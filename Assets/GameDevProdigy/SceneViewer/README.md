## Scenee Viewer - Utility for viewing scenes in editor

<b>Installation</b><br>
1. Open the Unity Editor.
2. Import the Scene Viewer utility package into your project.
3. Navigate to GameDevProdigy > Scene Viewer to open the tool.
4. The Scene Viewer window will appear in the Unity Editor.
5. Then It will show the available Scenes in your project.
6. You can Choose directories that you want to include or exclude
7. You can Click on the Scenes name to Navigate to that Scene

<b>Summary </b><br>

Easily manage scenes in Unity with the powerful Scene Viewer. Search, open, organize scenes, and save configurations for efficient workflow. Boost productivity in Unity. #SceneManagement #Productivity

<b>Description</b><br>

The Scene Viewer utility package for Unity is a comprehensive tool designed to simplify scene management and navigation within your projects. Whether you're working on a small game or a complex application, the Scene Viewer can greatly enhance your productivity and streamline your workflow.

Key Features:
1. Scene Search and Open: The Scene Viewer allows you to search for scenes within your project and open them directly from the tool. With a simple click, you can access any scene in your project without the need to navigate through Unity's project window.
2. Scene Organization: The utility automatically scans your project for scenes and organizes them into directories based on their file locations. This provides a clear overview of your project structure and makes it easier to locate and manage specific scenes.
3. Active Directory Management: The Scene Viewer enables you to define active directories, which are directories that contain scenes you're actively working on. You can easily mark directories as active or inactive within the tool, allowing you to focus on specific parts of your project at a given time.
4. Saved Configuration: The utility saves your active directory configurations, ensuring that your preferred directory settings are preserved even when you close and reopen the Unity Editor. This feature eliminates the need to manually set up your desired directory structure every time you start working on your project.
5. Intuitive Interface: The Scene Viewer provides a user-friendly interface within the Unity Editor, seamlessly integrating with your existing workflow. The tool's interface displays a list of scenes and their respective directories, allowing for quick access and easy navigation.

The Scene Viewer utility package empowers developers to efficiently manage scenes, improve organization, and optimize workflow when working on Unity projects. With its user-friendly features and powerful functionality, it is an essential tool for any Unity developer seeking to enhance their scene management capabilities.

Note: The Scene Viewer utility package is designed for use within the Unity Editor and does not have any impact on the runtime behavior of your projects.
